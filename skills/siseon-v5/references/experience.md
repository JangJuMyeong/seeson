# 브랜드와 경험

표기 **시선(see;線)**, 내부 코드명 siseon. 메인 문장 **삶의 선을 잇고, 더 나은 내일을 보다.** 인트로 문장 **수많은 가능성. 나에게 이어지는 하나의 선.**

흩어진 삶의 기록을 하나의 궤적으로 읽고, 나와 의료진의 판단을 이어 더 나은 다음 한 걸음을 찾는 Life Intelligence 서비스다. see는 맥락 속에서 나를 이해하는 시선, 線은 과거·현재·미래와 관계의 연결, 세미콜론은 앞선 시간과 다음 시간을 이어 주는 호흡으로 해석한다. Designing Your Life, Beyond Time을 상위 세계관으로 유지한다.

## 2026-10-27 시각 가이드

최우선은 지금 시연할 3D 소개다. 수만 가닥의 선이 빠르게 지나가고, 선택하면 역동적인 사건과 카메라 이동으로 은하 같은 공간에 들어간다. 이후에도 선택이 이어지며 목표에 가까운 길을 그라데이션으로 느끼게 한다. 첫인상의 놀라움과 선택의 인과관계가 중요하다.

순서: 빠른 선의 흐름 → 나의 선 선택 → 가능성의 은하 → 연속되는 갈림길 → 내가 고른 궤적과 다음 한 걸음. 실제 클릭·터치·키보드가 카메라·선·색·다음 선택을 바꾼다. 선택하지 않은 길도 보이며 거절을 벌하지 않는다. 반복 방문자는 인트로를 건너뛴다. 축소동작·중지·저사양 대체 경험을 제공한다.

‘올바른 방향’은 사용자 목표·의료진 판단·근거·실제 결과로 설명한다. 사람의 도덕적 우열이나 건강에 대한 확정 판정으로 색을 쓰지 않는다. 시연의 가상 선택과 실제 건강 예측을 구분한다.

## 개인의 선

지난 5년·오늘·앞으로 1년을 같은 축에 둔다. IRS+가 미래 방향과 범위의 모델 입력이 된다. 건강기준선·질환민감선의 정의와 근거를 상세에서 보여 준다. 설명 없는 종합 건강점수를 새로 만들지 않는다. 실제 수치는 관리 관심사·단위·비교 기준을 밝히고 데모는 도식임을 표시한다.

질문은 노드, 의사 확인은 도장, 개입은 근거와 이름이 붙은 노드다. 두 번째 W에서는 확인된 질환명과 판단이 이어진다. 범위 폭은 불확실성, 경로/색은 조건에 따른 추정이다. 관찰이 부족하면 유보하거나 넓히며 도장만으로 미래가 좋아 보이게 만들지 않는다.

차용 부품: 항목별 진료 노트, 후보 3개에서 선택/수정하는 의사의 3개월 목표선, 이탈 초기 순 선 묶음, 실제 확인자·시점이 있는 잠금화면 알림, 미래 편지, 동의한 가족의 선. 가족 유전체 비교는 제주 샌드박스 우선 검토 항목이다.
