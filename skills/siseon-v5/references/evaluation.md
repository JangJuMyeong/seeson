# 판단을 경험의 기록으로

회장 메시지의 해석: 세계관은 판단 기준, 실증은 측정·판단·수정의 반복이다. 울산·제주·심천·미국은 서로 다른 실증 맥락이며 승인·성과가 이미 있다고 표현하지 않는다.

## 6대 지침

1. IRS+ 질환 위험·관리 우선순위를 W·M1·M2·M3에 반영. 표시 방식은 법률 검토에 따르되 차별점을 삭제하지 않는다.
2. 의사 확정 뒤 W에서는 질환명을 의사 판단의 전달로 말한다.
3. 첫 W의 IRS+ 우선순위→의사의 확인으로 신뢰 경험. 두 기준선 유지. 비스타 우선 도입.
4. 일반 LLM과 달리 개인의 시간·근거·의사 판단을 연결. 개인 판정 금지, 출처 있는 지침 허용, 대화를 온톨로지에 누적.
5. 회색지대 기능은 플래그·비스타 사전 조율·제주 샌드박스 신청 목록으로 보존. 플래그는 승인이 아니다.
6. 기관 분석=IRB·협약, 의사 화면=보조참고, 연구군=본인 동의. 비스타·제주 계획에 포함하고 신뢰·이행률·의사 불일치율 측정.

## KPI와 운영

구동 안정성: 연속 경험 완주율, 지연 분포, 오류·재시도·중복·권한 차단·추적 누락, 3D 프레임 시간과 저사양/축소동작 대응.

수용성: 의미·색·선택 이유 이해도, 인트로 완료/건너뛰기, 환자·의사 신뢰도 전후 동일 문항. 신뢰에 응답률·표본 수를 함께 기록. 이행률은 기간 내 이행 확인 과제/평가 가능한 승인 과제이며 미응답·결측은 별도. 의사 불일치율은 수정·기각/검토 완료 제안이며 항목·기관·사례 특성을 보고한다. 무조건 낮추는 목표로 쓰지 않는다.

재무: 환자당 운영비, 실제 계약 매출·수납, 처리시간×실제 인건비, 회피 가능한 업무. 실측·가정·임상 효과를 구분한다.

컴피티션 2026-10-28~11-10, 발표 11-11. W→M1→M3 범위. 평가 34점 세계관/KPI/지침/3+1, 33점 기술·통합, 33점 현장 구축·운영·재구현.

배포 목표: 기관별 설정 1개+명령 1줄. 기관·어댑터·역할·근거 버전·동의/IRB·국가별 검토 플래그·승인 경로를 설정하고 비밀값은 별도 보관한다. 실행 도구가 없으면 목표로 표기한다. 비스타·제주 검토 목록에 IRS+ 환자 노출, 유전체 보조참고, 가족 선, 습관 시뮬레이션, 자동개입 수준을 둔다.

금지 패턴: 일반 건강 카드·루틴 앱, EMR 요약, 센서 타일, 분리된 원격관리 앱/포털, LLM으로 감싼 기존 기능. 해당하면 같은 궤적·판단·다음 행동 중심으로 다시 설계한다.
