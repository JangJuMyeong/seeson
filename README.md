# 시선 see;線 — CG인바이츠 3D 콘셉트 데모

**삶의 선을 잇고, 더 나은 내일을 보다.**

## 실행

```sh
./run-demo.command
```

그런 다음 http://127.0.0.1:4173 을 연다. Python 3가 필요하다. 정적 파일은 dist/에 있고 빌드·API 키·패키지 설치는 필요 없다. 이 명령은 시연 서버 실행이며 병원 통합 서비스 설치 명령이 아니다.

## 시연 순서

1. 12,000개의 빠른 선과 입체 은하를 본다.
2. ‘나의 선을 찾다’를 누르고 원하는 내일을 고른다.
3. 갈림길 세 번을 선택한다. 선택한 방향으로 카메라가 이동하고 빛의 파동이 생긴다. 목표에 따라 첫 제안도 달라진다.
4. 나의 선에 남은 선택을 보고 의료진과 확인하고 싶은 질문을 남긴다.
5. 다음 선택으로 이어 가거나 이전 선택으로 돌아간다. 반복되는 선택은 같은 세션의 앞선 기록과 이어진다.

상단 Ⅱ/▷는 움직임 중지·재생이다. 시스템의 동작 줄이기를 따르고, 인트로 건너뛰기·키보드 1/2/3·이전 선택·처음으로를 제공한다. CG Invites 로고는 공식 원본을 비율 그대로 배치했다.

## 구현 경계

- WebGL 3D와, 그래픽 가속을 사용할 수 없을 때 3D 좌표·카메라·원근을 직접 투영하는 소프트웨어 렌더러를 제공한다. 둘 다 단일 그림이나 재생 동영상이 아니다.
- 기본 WebGL 모드는 12,000개 통과 선, 1,000개 곡선 궤도, 18,000개 입자이며 화면 크기에 따라 부하를 줄인다. 숫자는 가상 그래픽 개수이며 실제 환자 수·예측 사례 수가 아니다.
- 모든 선택은 가상 시나리오다. 색·밝기는 사용자 목표와의 연결을 표현하며 의학적 옳고 그름·위험 감소·치료 효과를 의미하지 않는다.
- 현재 기록은 열린 탭의 메모리에 있다. 새로고침하면 초기화된다. 의료진에게 전송하지 않으며 로그인·환자 데이터·유전체·EMR·진단·실제 예측·푸시·JITAI 엔진·Flutter 앱은 아직 연결하지 않았다.
- 공식 기관 승인·인허가나 임상·재무 효과를 입증한 서비스가 아니라, 컴피티션에 사용할 시각·상호작용 콘셉트다.

## 제품 기준과 연결

[시작 설계](../siseon-starter/START-HERE.md), [스킬](../siseon-starter/skills/siseon-v5/SKILL.md).

| 이번 기능 | 지침 | 3+1 |
| --- | --- | --- |
| 3D 인트로·개인 목표 선택 | 3·4의 진입 경험 | 온톨로지에 들어갈 맥락 수집 입구 |
| 선택 기록·질문 노드 | 4 | 온톨로지의 경험 구조 |
| 의료진과 확인할 다음 단계 제시 | 2·4의 연결 준비 | Human in the loop의 진입점; 실제 확인은 미구현 |
| 움직임 중지·경량 3D·모바일 화면 | 안정성·수용성 KPI 지원 | 임상 3+1 기능으로 과장하지 않음 |

금지 패턴 점검: 건강점수·숫자 카드·루틴 목록·EMR 요약·센서 대시보드·채팅창 없이 선과 선택을 중심에 두었다. 실제 M1·M3는 후속 구현 대상이다. 개인 판정과 지침 인용을 섞지 않으며 현재 데모에는 개인 진단·의료 지침 수치가 없다.

## 파일

- dist/index.html, styles.css: 브랜드·접근성·반응형 UI
- dist/app.js: 목표·선택·질문·되돌리기·연속 경험
- dist/scene.js: WebGL 공간·카메라·선·파동
- dist/software-scene.js: 가속 불가 환경의 원근 3D
- dist/vendor/: Three.js 0.180.0, MIT 라이선스 동봉
- dist/assets/cg-invites-white.png: 공식 회사 로고
