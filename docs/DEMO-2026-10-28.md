# 2026-10-28 시연 준비

시연 스냅샷: `demo-2026-10-28`. 한국 시간 기준 내일 시연용. 별도의 예약·알림은 설정하지 않았다.

## 현장에서 열기

1. 노트북에 저장소 또는 전달 ZIP을 준비한다. Node 22+ 또는 Python 3가 설치되어 있어야 한다.
2. macOS: `run-demo.command`. Windows: `run-demo.bat`. 터미널이라면 `npm run dev`.
3. `http://127.0.0.1:4173/?lang=ko`를 연다. 중국어는 `?lang=zh`, 영어는 `?lang=en`.
4. 이미 연습한 기록이 있으면 이어보기 → 하단 ‘가상 사례 새로 시작’ → 확인. 목표 선택 화면에서 상단 로고를 누르면 새 인트로로 돌아간다.
5. 시연 전에 실제 발표 기기·브라우저·화면 공유 환경에서 한 바퀴 완주한다. 화면 확대는 100%부터 시작한다.

## 약 3분 흐름

| 구간 | 조작 | 한 문장 설명 |
| --- | --- | --- |
| 0:00–0:25 인트로 | 선 찾기 → 목표 선택 | 수많은 가능성에서 나에게 이어지는 한 선을 찾습니다. |
| 0:25–0:55 W | 질문 남기기 → 의사와 같은 선 보기 | 기록뿐 아니라 질문이 생긴 생활 맥락도 이어집니다. |
| 0:55–1:25 M1 | 판단·계획 확인 | 의사의 판단이 이 선 위에 남고, 이후 발화의 근거가 됩니다. |
| 1:25–1:50 퇴원 인계 | 같은 선 이어보기 → 퇴원 3일 뒤 | 퇴원해도 이전 계획과 연결이 끊기지 않습니다. |
| 1:50–2:25 M3 | 근거 체크 → 제안 확인 → 나의 화면 | 측정 공백을 악화로 단정하지 않고 사정부터 묻습니다. |
| 2:25–3:00 W 복귀 | Yes → 측정 재개 기록 → 일상 복귀 | 의사 확인·질환명·나의 응답이 남은 같은 선으로 돌아옵니다. |

추가 시연: 진단 보류를 선택하거나 ‘지금은 어려워요’를 누른다. 거절은 실패 점수 대신 다음 판단의 맥락이 된다. 이 경우 관찰 없이 미래 띠를 좁히지 않는다.

중국어·영어 발표 대본은 [제품 문서](PRODUCT-AND-DEMO.md)의 해당 문단을 사용한다. 언어를 바꾸어도 기록은 유지된다. 완전히 중국어 사례로 시작하려면 중국어 선택 후 새 사례에서 기본 질문을 저장한다. 기존 한국어 질문을 중국어로 바꾸어 쓰지 않는다.

## 복구

- 네트워크 문제: 로컬 URL 사용. 앱·로고·라이브러리는 동봉되어 있다. 지침 원문 링크는 별도 인터넷 필요.
- GPU 문제: 자동 소프트웨어 3D 전환. 상단 Ⅱ로 움직임을 멈춰 설명할 수 있다.
- 포트 사용 중: `npm run dev -- --port 4174`로 바꾸고 해당 URL을 연다.
- 기록이 남아 있음: UI의 새 사례 기능을 사용한다. 브라우저 전체 데이터를 지울 필요가 없다.
- 저장 제한: 화면의 ‘이 탭에서만 유지’ 안내를 따른다. 발표 도중 탭을 새로고침하지 않는다.
- 사이트 로그인/권한 문제: 기존 사이트는 비공개다. 로컬 패키지로 시연한다.

## 발표에서 구분할 것

“가상 사례에서 연속 경험과 판단 기록을 보여드립니다.”

실제 환자·의사·EMR·위험도·건강 개선·자동 발송·재무 개선이 입증된 것처럼 말하지 않는다. 테스트 결과는 소프트웨어의 상태 전이와 실행 재현성에 대한 증거다. 신뢰·이행률·의사 불일치율·재무 효과는 다음 실증의 측정 대상이다.
