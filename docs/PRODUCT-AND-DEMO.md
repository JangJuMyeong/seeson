# 시선 · 见线 · SEE;LINE — CG Invites

3D 인트로에서 선택한 한 사람의 선이 **W → M1 → M3 → 다시 W**로 이어지는 3개 언어 인터랙티브 데모. 2026-10-27 업데이트.

## 브랜드의 초월 번역

| 버전 | 이름 | 핵심 문장 | 의미 |
| --- | --- | --- | --- |
| 한국어 | 시선 · see;線 | 삶의 선을 잇고, 더 나은 내일을 보다. | 바라봄과 이어지는 선 |
| 简体中文 | 见线 · see;線 | 连起生命的轨迹，看见更好的未来。 | 삶의 연결을 발견하고 더 나은 방향을 봄 |
| English | SEE;LINE | Every choice, a new direction. | 선택이 다음 방향을 만드는 연속성 |

중국어는 한국어 발음의 음역 대신 ‘见’의 발견·바라봄과 ‘线’의 연결·궤적을 결합했다. ‘生命线’는 개인의 시간 궤적을 표현하는 은유다. CG Invites 공식 로고는 세 버전에서 동일하게 유지한다. 언어 선택은 이름만 바꾸지 않고 인트로·질문·의사 확인·개입·설명·오류 문구까지 전환한다. 이용자가 쓴 질문은 번역으로 덮어쓰지 않고 입력 언어와 원문을 보존한다.

## 3분 시연

1. **인트로**: 수많은 입체 선과 은하 → ‘나의 선을 찾다’ → 원하는 내일 선택.
2. **W**: IRS+ 기저 레이어, 두 기준선, 과거부터 미래 범위까지 같은 선을 본다. ‘질문을 내 선에 남기기’를 누른다.
3. **M1**: ‘의사와 같은 선 보기’. 질문 원문과 맥락이 그대로 나타난다. ‘고혈압으로 확인’ 또는 ‘진단 보류’를 선택하고 판단·계획을 확인한다.
4. **M3 인계**: ‘퇴원 후 같은 선 이어보기’. 생략된 입원 과정의 가상 퇴원 계획이 연결된다. ‘퇴원 3일 뒤’를 누른다.
5. **의료진 확인**: 측정 공백의 이유를 살펴본다. 근거·책임 의료진을 확인하는 체크 후 제안을 연결한다.
6. **환자 응답**: ‘나의 화면’으로 전환한다. ‘네’면 가상 후속 측정 기록을 연결하고, ‘지금은 어려워요’면 시간 재검토 후보가 남는다.
7. **다시 W**: 의사 확인, 질환명 전달 또는 진단 보류, 개입과 응답이 같은 선에 남는다. 관찰이 추가된 경우만 미래 띠의 관찰 불확실성을 줄인다.

화면 하단의 ‘가상 사례 새로 시작’으로 새 시연을 만들 수 있다. 새로고침 후에는 인트로의 ‘이어서 내 선 보기’를 누른다. 언어 전환은 사례를 초기화하지 않는다. 같은 브라우저에만 저장되며 여러 기기 간 동기화는 없다. 저장이 불가능한 환경에서는 해당 탭 안에서 유지하며 상태를 표시한다.

### 中文讲解

“万千可能中，我们先找到自己的那条线。过往记录、此刻的生活情境与就诊前的问题，一起来到医生面前。医生的确认会留下，出院后的关怀也沿着同一条线继续。愿意尝试或暂时不方便，都会成为下一次理解的背景。重新回到日常时，我们看到的仍是同一个人，却多了一层理解。”

点击顺序：找到我的生命线 → 选择愿望 → 把问题留在线上 → 与医生看同一条线 → 确认判断与计划 → 进入出院后 → 查看出院3天后 → 核对依据并确认建议 → 切换我的视角 → 回应 → 重回日常。

### English narration

“Among many possibilities, we find one line that is yours. Your records, everyday context and question arrive together at the consultation. The clinician’s judgment stays on that same line after discharge. Accepting a suggestion or saying that now is difficult both become context for the next decision. When we return to everyday life, it is the same person, understood more deeply.”

Click sequence: Find my line → choose an intention → add a question → clinician view → confirm or defer → after discharge → day 3 → review evidence and approve → patient view → respond → return to daily life.

## 구현과 경계

- 3D 인트로: Three.js WebGL 공간과 카메라 이동. GPU를 사용할 수 없으면 xyz 좌표와 원근 투영을 사용하는 Canvas 렌더러로 자동 전환한다. 12,000개 통과 선은 그래픽 개수이며 실제 환자 수가 아니다.
- 개인 선: 원근·포인터 반응이 있는 공간 궤적, IRS+ 층, 두 기준선, 미래 띠, 날짜를 가진 노드. 미래 도형은 개념 예시이며 보정된 임상 확률·정량적 시간 그래프가 아니다.
- 하나의 `trajectory_id`: 질문, 확인, 퇴원 인계, 이탈 신호, 승인 제안, 응답, 후속 관찰을 같은 객체에 추가한다. 출처·행위자·관련 노드·발생일·기록시각·정정 연결을 보존한다.
- 승인 게이트: 환자 역할의 의사 확인 금지, 근거·동의·연결 의료진·확인 범위 검사. 최신 판단이 바뀌면 이전 승인을 재사용하지 않는다. 새 승인에는 새 응답·관찰이 필요하다.
- 재귀적 개선: 거절 후 시간 재검토 **후보**가 기록된다. 의료진 검토 전에 정책·개입을 자동 변경하지 않는다.
- 브라우저 역할 전환과 클라이언트 검증은 **가상 시연**이다. 실제 인증·권한 통제·변조 방지 감사 서버·JITAI 운영 엔진이 아니다. 의료진에게 실제 전송하지 않는다.
- 유전체·웨어러블·EMR·퇴원 자료는 합성 데이터다. Flutter 환자 앱, 서버 통합, 병원 전체 선 묶음, 실제 예측, 임상·재무 효과 검증은 후속 구현이다.

## 개인 판정 / 지침 인용 / 의사 확정 전달

- 금지 개인 판정: “당신은 고혈압 전단계입니다.” AI 문구로 쓰지 않는다.
- 일반 지침: 표준화된 반복 진료실 측정과 진료실 밖 측정을 강조한다는 일반 설명에 [대한고혈압학회 2026 지침 하이라이트](https://doi.org/10.5646/ch.2026.32.e31)를 연결한다. 한국 지침을 중국 진료 기준인 것처럼 바꾸지 않는다.
- 의사 확정 전달: “김서윤 의사가 10/29 고혈압으로 확인한 가상 기록입니다.” 확인 노드가 존재할 때만 전달한다. 김서윤과 서연은 가상 인물이다.

**신뢰·이행률·의사 불일치율**을 반드시 실증한다. 이행률은 ‘Yes 클릭’이 아닌 승인 계획 대비 확인된 후속 행동으로 집계한다. 의사 불일치율은 의사에게 실제 제시한 동일 범위의 후보 중 수정/기각 비율로 정의하고 보류는 별도로 기록한다. 이 데모에는 의사에게 제시할 임상 AI 후보 엔진이 없으므로 진단 보류율을 불일치율로 대체하지 않는다. 실제 수치·임상 성과·재무 절감액은 아직 측정하지 않았다.
